# PixaShop User Manual

By AIWebDesignFirm · Edition 0.20.2

Your vision. Down to the pixel.

## Install and activate

PixaShop is a desktop image editor by AIWebDesignFirm. Start with a copy of an image you can experiment with.

1. Download the installer for your computer from the PixaShop page. On Mac, open the DMG, drag PixaShop into Applications, and open it from Applications. Close an older copy before replacing it. On Windows or Linux, extract the downloaded archive before opening the app.
2. If the app shows a device code, choose Activate this device. Sign in on the website with your free Pixa account, and approve only the code displayed on your own computer.
3. Return to PixaShop and choose Check again if the editor has not opened. An internet connection is required for account access checks.

Enter your account password only on the website. Free Pixa access does not need payment details. The device-approval screen is separate from Apple signing and notarization.

## Your first edit

Open an image, add a title, and export a copy. Keep the editable project as well.

1. Choose File → Open… and select an image. To start a blank document instead, choose File → New… and review its dimensions before creating it.
2. Select the Horizontal Type Tool (T), click on the canvas, and type a short title. Use the character controls to change its font, size, and color.
3. Choose File → Save As… and save an editable copy as .pcraft, or choose PSD Document when you need a PSD. Give the file a new name so your original stays intact.
4. Choose File → Export → Export As…, select PNG or JPG, review the preview, then click Export and choose where to save.

Saving your project preserves the structure for later edits. Exporting creates an image for sharing.

## Find your way around

The canvas is your image. The toolbox chooses an action. Panels show what that action affects.

1. Use the toolbox to choose tools such as selection, brush, move, and type. Hover over an icon to read its label.
2. Use the Layers panel to select the layer you intend to edit. A selected text layer, image layer, or mask can behave differently.
3. Use Properties and the controls associated with the active tool to adjust its settings.
4. Use History or Edit → Undo to step back after an unwanted change. Save regularly; undo history is not a replacement for a saved file.

When a tool seems unresponsive, first check the active layer, any selection, and whether the document is still in text-editing mode.

## Work with layers

Layers let you arrange images, text, and adjustments independently. Higher layers can cover lower ones.

1. Select a layer in the Layers panel before editing it. Use the panel’s visibility control to compare a layer with the rest of the image.
2. Keep text and image elements on separate layers when you want to move or change them independently.
3. Review the layer’s opacity and blend settings if its appearance is unexpected.
4. Save as .pcraft or PSD to retain editable structure. Check an important PSD after reopening it, especially when it contains complex effects or features from another editor.

PNG and JPG are flat outputs. They do not preserve your stack of editable layers.

## Select an area and add a mask

A selection limits the area you work on. A mask hides pixels without immediately erasing them.

1. Use the Rectangular or Elliptical Marquee Tool for a simple shape, or a Lasso tool for a hand-drawn area. Drag around the part you want to use.
2. To soften an edge, review Select → Modify → Feather…. Use Select → Inverse if you need the opposite area.
3. Select the intended layer, then choose Layer → Layer Mask → Reveal Selection to show only the selected area. Hide Selection hides that area instead.
4. Choose Select → Deselect when you no longer need the selection. Use the layer-mask commands to disable or remove the mask if you want to compare the original.

Apply a mask only when you are ready to commit its result to the layer’s pixels. Keep an editable copy before destructive changes.

## Add and edit text

Use the Horizontal Type Tool to create a title, caption, or paragraph.

1. Choose the Horizontal Type Tool (T). Click for a line of text, or drag a rectangle to create a paragraph text box.
2. Type your text and adjust font, size, alignment, and color using the text controls. Fonts available on your computer can affect the result.
3. To revise the words, select the type tool and click the existing text. Hold Shift while clicking if you want to start new text over an existing text layer.
4. For an effect, select the text layer and choose Layer → Layer Style, then an effect such as Drop Shadow… or Stroke….

Rasterizing a text layer turns it into pixels. Keep the editable text version if you expect to change the words later.

## Adjust light and color

Adjustment layers keep a color change separate from the original image.

1. Select the layer where you want to add the adjustment, then choose Layer → New Adjustment Layer.
2. Start with Brightness/Contrast…, Levels…, Curves…, or Hue/Saturation… depending on the change you need.
3. Adjust the settings in Properties. Compare the image with the adjustment layer hidden and visible.
4. To restrict an adjustment to an area, make a selection and use Layer → Layer Mask → Reveal Selection on the adjustment layer.

Image → Adjustments changes the layer’s pixels directly. Prefer a separate adjustment layer when you want to revise the settings later.

## Paint with brushes

Paint on a separate layer when you want to keep your brushwork apart from the original photo.

1. Choose the intended layer and select the Brush Tool.
2. Review brush size, opacity, and color before painting. Try a short stroke and undo it if the result is not what you want.
3. Use smaller strokes and zoom in for edge work. If strokes affect only part of the image, check whether a selection or layer mask is active.
4. Save your layered project before flattening or exporting the final image.

If you paint on a mask instead of an image layer, you are changing visibility rather than painting color onto the image.

## Save an editable project

Keep a project file for future changes and an exported image for sharing.

1. Use File → Save As… for a new project name or file type. PixaShop’s native project extension is .pcraft. PSD Document is available for PSD exchange.
2. After choosing a project location, File → Save updates that file. Wait for saving to finish before closing the app or moving the file.
3. Use File → Open Recent to return to a recent document. If you moved or renamed it, open it again through File → Open….
4. For important work, keep a backup and reopen a saved copy to check its appearance and layers.

File compatibility is not a promise of identical results in every editor. Complex documents may produce warnings or differences. Check the result before overwriting an original.

## Export a finished image

Export creates a flat image while leaving your open layered project available for editing.

1. Choose File → Export → Export As….
2. Select PNG when you need transparency. Choose JPG for a photo without transparency, or another format offered in the dialog when appropriate.
3. Review quality, transparency, scale, and the preview. JPG cannot preserve transparent areas.
4. Click Export, select a filename and location, then open the exported image to check its dimensions and appearance.

Reducing export scale reduces the output dimensions. Save the full-resolution project separately if you may need a larger version later.

## Account, privacy, and updates

Your image files stay on your computer. PixaShop requires an internet connection to verify account access.

1. Use the Pixa account page to manage your free access and approved devices. No card is required and access has no scheduled account expiration. Existing unrelated paid services, if any, are managed separately.
2. Choose Help → Check for Updates to look for PixaShop releases from AIWebDesignFirm. The update channel does not install the original PhotoCraft application.
3. Version 0.20.1 requires a one-time manual installation of 0.20.2 to gain the Mac updater. Version 0.20.2 includes Install and restart for future Mac releases; save open work before using it.
4. Windows and Linux currently use the website download flow. Close the app before replacing an installation, and keep your project files backed up.

The Mac installer for 0.20.2 was signed and notarized. A full real-world Install and restart upgrade test is still pending. Signing does not guarantee that every editing feature is free of bugs.

## When something does not work

Start with the file, selected layer, and active tool before repeating an action.

1. If the editor asks for activation, confirm that you signed in to the intended account and approved this computer’s displayed code. Check internet access, then choose Check again.
2. If edits are invisible, inspect layer visibility and opacity, the active mask, any selection, and the active tool. Try Edit → Undo if a recent change caused the problem.
3. If a file fails to open or looks different, keep the original untouched and try a copy. Record the format and the exact warning. Do not assume an imported document has perfect feature compatibility.
4. If the app stops responding, give a large operation time to finish. Before quitting, save any work you can. For a useful problem report, record your operating system, app version from Help → About PixaShop, and the steps that caused the issue.

PixaShop is still developing. These workflows were checked against the 0.20.2 source and existing guides; full interactive testing of every editing feature is not complete. There is no PixaShop Discord currently.
